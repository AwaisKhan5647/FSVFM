────────────────────────────────────────────────────────────────────────────────
DATASET FORMAT (accepted by composite_dataset.py)
────────────────────────────────────────────────────────────────────────────────
Option A — Folder-structure (auto-labelled):
  dataset_root/
    real/           ← any folder with "real" in name → label 0
      video1/
        frame_001.jpg
    FaceSwap/       ← any other name → label 1 (fake)
      video2/
        frame_001.jpg

Option B — Label file (.txt, space-delimited):
  --train_root /dataset_root --train_label_file /path/train.txt
  train.txt format:  /abs/path/to/frame.jpg 0
                     relative/path/frame.jpg 1

Option C — Multiple datasets (all repeated):
  --train_root /dataset1 --train_root /dataset2 --train_root /dataset3
  --val_root   /dataset1 --val_root   /dataset2

Flags:
  --balance           oversample minority class to 1:1 real:fake ratio
  --max_per_dataset N cap each sub-dataset at N samples

TRAINING HYPERPARAMETERS (upstream FSFM defaults, ViT-L)
────────────────────────────────────────────────────────────────────────────────
Model         : vit_large_patch16  (ViT-L/16, 307M params)
Input size    : 224x224
Batch/GPU     : 32  (effective = 32 * 2 GPUs = 64)
Epochs        : 50
Warmup        : 5 epochs
Base LR       : 5e-5  (actual LR = blr * eff_batch / 256 = 5e-5 * 64 / 256 = 1.25e-5)
Layer decay   : 0.90
Weight decay  : 0.01
LR schedule   : cosine (per-iteration)
Drop path     : 0.1
Mixup alpha   : 0.8
CutMix alpha  : 1.0
RandErase     : 0.25
Augmentation  : RandAugment (rand-m9-mstd0.5-inc1) + center crop for val
Normalization : ImageNet mean/std (--normalize_from_IMN)
               or VGGFace2 mean=[0.5482, 0.4234, 0.3655] std=[0.2789, 0.2439, 0.2349]
Optimizer     : AdamW with layer-wise LR decay
Loss          : SoftTargetCrossEntropy (when mixup active)
AMP           : torch.cuda.amp.autocast + NativeScalerWithGradNormCount
